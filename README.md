# ganexh — Ganesh Shah portfolio

Official portfolio site for **[ganeshshah.com](https://ganeshshah.com)** by [Ganesh Shah](https://github.com/ganexhshah).

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- GSAP + Framer Motion

## Frontend

```bash
cd frontend
npm install
npm run dev
```
